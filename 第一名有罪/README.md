## 三条铁律

1. **一章一循环**：写手 → 评审 → 主编定稿 → 档案员归档。任一步失败就地重跑，不回退整批。
2. **绝不在同一个 agent 里既写又审**。评审一律新建独立子代理。
3. **知识边界是闸门**：写手只准用 `04-知识边界.md` 中标 ✅ 的信息；用了 ❌ 的信息，该章整章重写。

---

## 一章怎么写（最短路径）

```
1. 读 03-细纲（本章条目）+ 04-知识边界（本章时刻）+ 06-连续日志（最后 3 条）
2. 派写手 subagent（简报模板见 10-批次脚本.md），产出 drafts/chNNN.draft.md
3. 写手回合结束后，派评审 subagent，产出 reports/chNNN.review.md
4. 全绿 → 我（主编）定稿 chapters/chNNN.md；有黄/红 → 整改后重审
5. 归档：更新 04 / 05 / 06 / 07 四个文件
```
