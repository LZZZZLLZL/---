# 15 · 全书终审（对齐 novel-solo 规格）

> 来源：`dsh-novel-solo` 预设（`单核写作主理`）。
> 它的硬要求：**章节审核与全书终审一律新建独立子代理执行，主代理绝不代审**；
> 每章必审、绿黄红三色、全绿才放行；审核输出一行一字段；报告落盘。

## 一、与本项目既有规程的冲突（已裁定）

| 项 | novel-solo 预设 | 本项目 `08 §10` / `13` | 裁定 |
| --- | --- | --- | --- |
| 章节审核 | 每章新建独立子代理，主代理绝不代审 | 主代理自审（控本） | **写作期沿用自审**（已跑完 120 章，回不去）；**终审按预设执行** |
| 审核报告 | 每章一份，落 `审核报告-第N章-章名-vX.md`，重审时删旧版 | 存 `reports/` 按轮次保留、不覆盖 | 终审报告写 `reports/终审-*.md`，**不删历史**（保留可审计性） |
| 版本管理 | 整章大改升 `v(X+1)` 并删旧版 | 直接改 `chapters/`（git 留版本） | **用 git**（本项目已有 7 个里程碑分支，比文件名版本更可查） |
| 合订 | 全书终审通过后合订 `书名.txt` | 无 | 终审通过后生成 `第一名有罪-全本.txt` |

## 二、终审维度（A—H，采用预设原文判据）

| 维 | 判据 |
| --- | --- |
| **A 设定一致** | 与世界观 / 核心规则 / 禁止内容无矛盾 |
| **B 人物性格一致** | 言行由性格底色与动机驱动，压力下反应符合深层欲望与核心恐惧，口吻与档案逐项比对无冲突 |
| **C 目录一致** | 关键情节点逐点核对正文是否落实；未落实判黄、整段缺失判红 |
| **D 叙事质量** | 视角严格执行（限知只写主角可感知的触/听/气味/余光）；文风/镜头/节奏/情绪渲染，忌直写心理标签 |
| **E 正文规则** | 字数区间 / 章末钩子 / 承上启下 |
| **F 禁AI腔（重点）** | 六维度：句式模板 / 词汇套话 / 情绪直给 / 结构雷同 / 信息稀释 / 人物失真。命中 1 处判黄；同类 ≥2 处或整段无信息重复判红；**先否定后转折即红** |
| **G 剧情逻辑连贯（权重最高）** | 本章必须有**新事件**（上一章未发生、且改变角色状态或推进关系）；跨章因果完整；前章钩子必须兑现，未兑现判红 |
| **H 动作与物理逻辑** | 动作衔接清晰；身体位置与感官描写匹配；无力学/解剖学错误 |

**三色**：绿=放行｜黄=不合格（附原因+修改建议，**须改情节结构而非只换词**）｜红=打回重写。
**全绿才放行；出现黄即不合格。**

## 三、终审输出格式（一行一字段）

```
审核结果：
评级：
判定明细：维度|绿黄红|问题原因|修改建议
结论：
```

## 四、跨章专项（终审的重点，A—H 之外的 i/j）

| 项 | 判据 |
| --- | --- |
| i 文档完整 | 设定圣经 / 大纲 / 细纲 / 边界 / 伏笔表 / 连续日志 / 进度看板 字段齐全 |
| j 合订质量 | 首行书名、目录照大纲、无模板残留、无缺漏 |

跨章还要查：**同一句式 / 收尾句 / 比喻跨章 ≥2 处判红**（叙述层重复即删）；
但**角色口癖、标志性称呼、习惯动作符合人物档案的，属人设一致性，不判重复**。

## 五、执行方式（控本版）

- **按批次派独立评审子代理**，每个代理审 **8—10 章**（复用已有评审代理，不每章新开）；
- 每组评审要拿到：`01-圣经.md`、`02-总大纲.md`、`06-连续日志.md`（时间线与钱账）、`04-知识边界.md`、以及它负责的那批正文；
- 评审**只读不改**，产出报告交主代理，由主代理执行整改（预设原话：结论为「修改后放行/打回重写」时，由主代理新建版本执行）；
- 报告落 `reports/终审-第N批.md`。

## 六、已知并接受的例外

- 主代理在**写作期**自审了 120 章（与预设冲突），这是为控本做的主动取舍，记在此处备查；
- 终审由独立子代理执行，**满足预设对「独立审核」的核心要求**。
