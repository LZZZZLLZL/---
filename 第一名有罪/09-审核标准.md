# 09 · 审核标准（A–H + 三色判定 + 禁AI腔）

> 本标准合成自两处：
> ① 开源插件 `dsh-novel-solo`（Tkingxiao）随包预设 `novel-solo` 的审核规范——A–H 八维度、绿黄红三色、六维禁AI腔、强制前置检查；
> ② 本项目 `08-写作工作流.md` 自有的角色隔离、知识边界、批次闸门、伏笔表。
>
> **写作与审核共用同一份清单。** 审核一律新建独立子代理执行，主代理绝不代审。

---

## 一、强制前置检查（每章动笔前，三项全过才写）

1. 本章有没有发生**上一章没发生过的新事件**？（换了场景但做同样的事不算新事件）
2. 本章结束时，角色状态是否与开头不同？（知道 / 做到 / 感受到，至少一项变了）
3. 本章是否回答了上一章结尾的「然后呢」，并在结尾抛出新的「然后呢」？

写完用同样三点自检，不合格重写。**前章钩子本章必须兑现，未兑现判红。**

## 二、A–H 八维度

| 维度 | 判定内容 | 权重 |
| --- | --- | --- |
| **A 设定一致** | 与 `01-圣经.md` 的世界观、核心规则、信物系统无矛盾 | 高 |
| **B 人物性格一致** | 言行情绪决策由性格底色与动机驱动；压力下反应符合深层欲望与核心恐惧；口吻与人设连贯；与人物卡逐项比对 | 高 |
| **C 大纲一致** | 关键情节点逐点核对；伏笔与目录对齐；未落实判黄，整段缺失判红 | 高 |
| **D 叙事质量** | 视角严格执行（限知视角只写主角可感知的触/听/气味/余光）；文风、节奏、情绪渲染；忌直写心理标签；抽查意象系统是否落实 | 中 |
| **E 正文规则** | 字数区间 2800—3500 / 章末钩子 / 承上启下 | 中 |
| **F 禁AI腔** | 按下方六维度判定，命中 1 处判黄，同类 ≥2 处或整段无信息重复判红；**先否定后转折句即红** | 高 |
| **G 剧情逻辑连贯** | **权重最高**——本章必须有新事件；章内与跨章因果链完整；时间线无冲突；动机充分；伏笔有回收；衔接无漏洞 | 最高 |
| **H 物理与动作合理** | 动作衔接清晰（转身/移动/肢体位置要有过渡）；身体位置与感官描写匹配；生理设定前后一致；无力学与解剖学错误 | 中 |

### 本项目附加维度（源自自有工作流）

| 维度 | 判定内容 |
| --- | --- |
| **I 知识边界** | 是否使用了 `04-知识边界.md` 中标 ❌ 的信息。**致命项，不通过即整章作废** |
| **J 称重** | 是否有一个被量化的东西放在秤上（钱 / 分数 / 感情）——这是本项目每章的硬指标 |

## 三、三色判定

| 色 | 含义 | 处置 |
| --- | --- | --- |
| **绿** | 达标放行 | 进入定稿 |
| **黄** | 不合格（轻微偏差） | 附问题原因 + 修改建议，整改后重审。**修改不能只是换词换比喻，必须改动情节结构本身**（新增事件 / 改变角色反应 / 推进关系）。只做文字润色的修改不予通过 |
| **红** | 严重问题 | 打回重写 |

**放行规则：A–H + I、J 全绿才放行。出现黄灯即不合格。** I 项为红则整章重写。

## 四、禁AI腔（写作与审核共用清单）

### 维度一 · 句式模板
- 先否定后转折的对比句（不是/并非…而是/只是/反倒…）——**即红**
- 万能过渡词：值得注意的是 / 总而言之 / 综上所述 / 与此同时 / 换句话说 / 从某种意义上说 / 显而易见 / 不难发现 / 事实上 / 实际上
- 句长均匀无参差；过度工整的对仗排比

### 维度二 · 词汇套话
- 神态套话：嘴角勾起 / 眼底划过 / 瞳孔微缩 / 喉结滚动 / 若有所思 / 意味深长 / 轻描淡写 / 语气平静无波澜
- 情绪套话：五味杂陈 / 百感交集 / 思绪万千 / 浑身一震 / 如坠冰窟 / 惊涛骇浪 / 令人窒息 / 心底泛起复杂
- **同一高频词每章限一次**

### 维度三 · 情绪直给
- 用形容词直接贴标签（他很难过 / 她很震惊）代替动作、情节、意象
- 直写心理标签而不通过行为外化

### 维度四 · 结构雷同
- 连续章节同构（同一起点 / 同一推进顺序 / 同一收尾方式）
- 场景结构重复：本章事件推进顺序与上一章高度一致 → **判红**
- 连续章节结尾用同一叙事结构或同一情感表达

### 维度五 · 信息稀释
- 同一信息 / 画面 / 道理重复（除非第二遍带新信息或推进作用）
- 低信息密度注水；空泛抽象描写（无具体细节支撑的宏大形容词）

### 维度六 · 人物失真
- 所有角色说话一个腔调
- 人物口吻与档案设定不符
- 用叙述者腔调代替人物自己的语言

### 特许句式（全书限用一次，已用尽）

- **第 4 章**：「我要一个证人。不是眼线。」——**先立后否**（不是「不是A，是B」），无「而是／只是／反倒」转折连词，且为细纲逐字指定的台词，判定**不构成判红句式**。
- 但这是**全书唯一一次**的「对照式定义」句式。**此后任何角色再出现同类对照句（先立后否或先否后立），一律判红。**

### 两条判定原则
1. **连词铁律**：段落逻辑衔接靠情节因果，不用「然而 / 与此同时 / 就在这时」等硬转折。
2. **重复判定**：**叙述层重复即删**——同一句式 / 收尾句 / 比喻跨章 ≥2 处、同一外貌 / 动作 / 感觉高频词每章限一次；**人设层一致不判重复**——角色专属口癖、标志性称呼、习惯动作，只要符合人物卡且随语境有变化，属于人设一致性。

D 叙事质量：绿 | 黄 | 红｜问题原因｜修改建议
E 正文规则：绿 | 黄 | 红｜问题原因｜修改建议
F 禁AI腔：绿 | 黄 | 红｜问题原因｜修改建议
G 剧情逻辑连贯：绿 | 黄 | 红｜问题原因｜修改建议

**落盘**：`reports/chNNN.review.md`。重审时创建新报告版本，旧版审核报告删除。
**只读审核，不改正文。** 结论为修改后重审 / 打回重写时，明确告知主代理由主代理执行整改。

## 六、版本化写作

| 动作 | 判定 | 操作 |
| --- | --- | --- |
| 小段修改 | 只改局部文字 / 段落，不动情节与结构 | 直接 edit 替换，**绝不升版本** |
| 整章大改 | 重写情节 / 结构 / 大段内容，或 edit 连续失败 ≥3 次 | 另存 `chNNN.v(X+1).md`，旧版保留（**不覆盖**） |

本项目的草稿/定稿约定：草稿 `drafts/chNNN.draft.md`（可覆盖），定稿 `chapters/chNNN.md`（**只增不改**，大改另存版本）。

## 七、审核触发与门禁

1. **每章必审，不审不交付。**
2. **审核一律新建独立子代理**，主代理绝不代审；子代理本身不能申请子代理。
3. **门禁**：上一章审核报告未落盘或含未整改的黄 / 红项 → 不得动笔本章。
4. **重审**：整改后派新子代理重审，黄 / 红项全部整改至全绿才放行。

---

## 八、全书终审（100 章完成后执行）

**执行方式**：新建独立子代理，只给项目目录，主代理静默等待。

**审查重点（跨章全局）**：

| 项 | 内容 |
| --- | --- |
| a | 设定一致：跨章无冲突 |
| b | 人物弧光完整：对照各人物卡的弧光设定，逐章变化是否连贯 |
| c | 伏笔全部回收：对照 `05-伏笔表.md`，F1—F22 是否都有回收 |
| d | 节奏平衡：是否出现连续平章、是否头重脚轻 |
| e | 逻辑自洽：前章承诺兑现，开篇关系有交代 |
| f | 无AI腔：跨章叙述层同一句式 / 比喻 ≥2 处即红（人物口癖不判重复） |
| g | 物理与逻辑合理 |
| h | 叙事方法落实：视角 / 意象系统 / 节奏 |
| i | 文档完整：必填字段齐全 |
| j | 合订质量：首行书名 / 目录照大纲 / 无模板残留 / 无缺漏 |

**落盘**：`审核报告-全书.md`。含黄或红即不合格；含红则结论必须为打回重写。
