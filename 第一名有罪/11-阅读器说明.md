# 阅读器使用说明

`reader.html` 是《第一名有罪》的专用阅读器：零依赖、单文件、离线可用（本地起 HTTP），专为读这本小说调过版式。

## 打开方式

**方式一（推荐）**：双击 `启动阅读器.command`
它会自动重建章节清单、找一个空闲端口起本地服务、并打开浏览器。

**方式二（手动）**：

```bash
cd 第一名有罪
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/reader.html
```

**为什么不能直接双击 `reader.html`**：浏览器禁止 `file://` 页面用 fetch 读本地章节文件。阅读器检测到这种情况会在正文区给出明确提示，不会白屏。

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 章节目录 | 左侧栏；已读完的章前面有一个小圆点 |
| 上一章 / 下一章 | 工具栏 `‹` `›`，或键盘 `←` `→`（也支持 `j` / `k`） |
| 阅读进度 | 底部细线 + 右上角百分比；点百分比可看"已读完 X / Y 章" |
| 位置记忆 | 每章的滚动位置自动保存，关掉再打开回到原处；下次打开自动回到最后读的那一章 |
| 书签 | 按 `B` 给当前位置加书签；左侧「书签」页签里查看/跳转/删除 |
| 全文搜索 | 按 `/` 或点放大镜，输入即搜（防抖 260ms），点结果跳到那一段 |
| 排版设置 | 按 `S` 或点 `Aa`：主题（浅色/米黄/夜间）、字号、行距、版心宽度、宋体/黑体 |
| 打印 | 浏览器打印时自动隐藏侧栏与工具栏，只出正文 |

**键盘速查**：`←/→` 翻章 · `B` 加书签 · `S` 排版 · `/` 搜索 · `T` 目录 · `Esc` 关闭弹层

所有偏好（主题、字号、书签、进度）都存在浏览器 localStorage，换浏览器不通用。

## 章节清单怎么来

阅读器读同目录的 `chapters.json`。这个文件**不要手改**，用生成器产出：

```bash
python3 工具-生成章节清单.py          # 生成 / 更新
python3 工具-生成章节清单.py --check  # 只检查是否与当前章节一致
```

生成器的规则：

- **章号与标题以 `02-总大纲.md` 为准**（唯一事实来源），不从正文里猜；
- 只有 `chapters/chNNN.md` 存在的章才进清单（没写的不显示）；
- 字数按正文汉字数统计。

所以每写完一章定稿，跑一次生成器，阅读器里就会多出那一章。

## 文件

| 文件 | 作用 |
| --- | --- |
| `reader.html` | 阅读器本体（单文件，零依赖） |
| `chapters.json` | 章节清单（由工具生成） |
| `工具-生成章节清单.py` | 从总大纲 + 正文章节生成清单 |
| `启动阅读器.command` | 双击启动：重建清单 + 起服务 + 开浏览器 |
