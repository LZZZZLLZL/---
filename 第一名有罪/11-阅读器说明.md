# 阅读器使用说明

`reader.html` 是《第一名有罪》的专用阅读器：零依赖、单文件、离线可用（本地起 HTTP），专为读这本小说调过版式。

## 打开方式

**方式一（推荐）**：双击启动器

| 系统 | 双击这个文件 |
| --- | --- |
| **Windows** | `启动阅读器.bat` |
| **macOS** | `启动阅读器.command` |
| Linux / 任意系统 | `python3 启动阅读器.py` |

两个启动器都只是薄壳，真正干活的是 **`启动阅读器.py`**（跨平台，逻辑只有一份）：
重建章节清单 → 找一个空闲端口 → 起本地服务 → 打开默认浏览器。
端口被占用会自动往后找（8765、8766……），控制台会打印实际地址。

**方式二（手动）**：

```bash
cd 第一名有罪
python3 -m http.server 8765          # Windows 上可用 py -3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/reader.html
```

**方式三（带参数）**：

```bash
python3 启动阅读器.py 9000      # 从 9000 起找端口
python3 启动阅读器.py --no-open # 不自动开浏览器
```

**为什么不能直接双击 `reader.html`**：浏览器禁止 `file://` 页面用 fetch 读本地章节文件。阅读器检测到这种情况会在正文区给出明确提示，不会白屏。

### Windows 注意事项

- **需要 Python 3**。没装的话，`启动阅读器.bat` 会打印 python.org 的下载地址并停住等你按键；
  安装时**务必勾选 `Add Python to PATH`**。启动器会依次尝试 `py -3` → `python` → `python3`，命中哪个用哪个。
- **路径里尽量避免中文或空格**（不是必须，但更省事）。项目目录名 `第一名有罪` 本身没问题。
- **控制台中文乱码**：`.bat` 已经执行 `chcp 65001` 切到 UTF-8；两个 Python 工具脚本也各自把
  stdout/stderr 重设为 UTF-8，所以即便在 GBK 代码页的老 cmd 里输出也是正常的。
- **推荐用 Windows Terminal 或 PowerShell**，老版 `cmd` 也能用。
- 端口被防火墙拦时，把 `127.0.0.1` 加进允许列表（启动器只绑定本机回环，不对外网开放）。

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 章节目录（分组） | 左栏按**十章群 / 支线**折叠成 16 组，默认只展开当前章所在组；点组标题展开/收起 |
| 目录筛选 | 目录上方输入框：支持**章名、章号、支线名、外传锚定**（如「孟凡」「外传」「骨架 ch044」）；命中高亮，并显示筛出多少章 |
| 侧栏折叠 | 点书籍标题右侧 `«`，或按 `[`，或点工具栏第一个 `☰` → **收起后正文更宽**（640px → 864px）；收起后工具栏出现 `»` 可随时展开 |
| 宽屏 | 工具栏 `⇔` 或按 `W`：版心 40em → 62em |
| 上一章 / 下一章 | 工具栏 `‹` `›`，或键盘 `←` `→`（也支持 `j` / `k`），`Home` / `End` 跳首末章 |
| 阅读进度 | 底部细线 + 右上角百分比；每章标题下有「字数 · 约几分钟」；点百分比看"已读完 X / Y 章 · 全书约 N 小时" |
| 位置记忆 | 每章的滚动位置自动保存；下次打开回到最后读的那一章，并在顶部弹一条「上次读到第 N 章（已读 X%）」提示，可一键回到那里 |
| 书签 | 按 `B` 加书签；左栏「书签」页签里查看/跳转/删除（跳转会回到当时的位置与段落） |
| 全文搜索 | 按 `/` 或点放大镜：**分批建索引**（面板右上角显示进度），结果**按章聚合**并标出每章几处，点任一条跳到那一段 |
| 排版 | 按 `S` 或点 `Aa`：预设（舒适/紧凑/大字/宽屏）、主题（浅色/米黄/夜间）、字号、行距、段距、版心、宋体/黑体、两端对齐开关 |
| 跨平台字体 | 字体栈覆盖三端：macOS 用 Songti SC / PingFang，**Windows 用 SimSun（宋体）/ Microsoft YaHei（微软雅黑）**，通用回退到思源宋体/黑体 |
| 深链接 | 地址栏 `#/ch/88` 直达第 88 章；换章时地址栏自动更新，可以随手收藏或分享 |
| 打印 | 浏览器打印时自动隐藏侧栏、工具栏与提示条，只出正文 |

**键盘速查**

| 键 | 作用 |
| --- | --- |
| `←` `→` / `j` `k` / 空格 | 上一章 / 下一章 |
| `Home` `End` | 第一章 / 最后一章 |
| `[` | 收起或展开侧栏（窄屏下等同开目录抽屉） |
| `W` | 宽屏开关 |
| `B` | 加书签 |
| `S` | 排版设置 |
| `/` | 全文搜索 |
| `T` | 目录抽屉（窄屏） |
| `G` | 光标跳到目录筛选框 |
| `Esc` | 关闭弹层 / 退出输入框 |

所有偏好（主题、字号、版式、书签、进度、折叠状态）都存在浏览器 localStorage，换浏览器不通用。
**主题在页面渲染前就写入 `<html>`**，所以夜间/米黄模式刷新时不会先闪一下白。

## 章节清单怎么来

阅读器读同目录的 `chapters.json`。这个文件**不要手改**，用生成器产出：

```bash
python3 工具-生成章节清单.py          # 生成 / 更新（打印分组摘要）
python3 工具-生成章节清单.py -v       # 连每章字数与阅读时长一起打印
python3 工具-生成章节清单.py --check  # 只检查是否与当前章节一致
```

生成器的规则：

- **章号与标题以 `02-总大纲.md` 为准**（唯一事实来源），不从正文里猜；
- **分部**同样从大纲解析：`### 第X幕 标题（起—止）· 副题` 得到十章群，**附录 C 的扩写章表**得到外传章并按支线归组；
- 只有 `chapters/chNNN.md` 存在的章才进清单（没写的不显示）；
- 每章带 `words`（汉字数）、`min`（按 400 汉字/分钟折算）、`group`（所属分部）、`anchor`（外传章锚定骨架的位置）。

所以每写完一章定稿，跑一次生成器，阅读器里就会多出那一章、并自动落到对应分部。

## 文件

| 文件 | 作用 |
| --- | --- |
| `reader.html` | 阅读器本体（单文件，零依赖） |
| `chapters.json` | 章节清单（由工具生成，含分部与阅读时长） |
| `工具-生成章节清单.py` | 从总大纲（含附录 C）+ 正文章节生成清单 |
| `启动阅读器.py` | **启动逻辑本体**（跨平台：重建清单 + 找空闲端口 + 起服务 + 开浏览器） |
| `启动阅读器.bat` | Windows 双击入口（找 Python → 调 `启动阅读器.py`） |
| `启动阅读器.command` | macOS 双击入口（找 python3 → 调 `启动阅读器.py`） |
