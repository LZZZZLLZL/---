- 分数：周予晚年级第一（上学期期末也是第一）；李洋 46/47（人物卡背景，正文未报）
- 物件：牛皮纸信封（未封口、边角起毛）；收据（南洲一中 / 贫困生补助 / 日期填上学期末最后一天 / 签名栏上一行已有笔迹，正文未写名字）；李洋的旧自行车（车座用电工胶布缠两圈）；市二院门诊条子（上礼拜六的，被汗浸黄）；排课表（四月那几格用铅笔画了圈）；校门口银杏标牌「1897—」

### ch002 · 第一名坐在我前面两排

- 时间：与第 1 章同日晚自习，18:25—22:00；晴转夜，三月中旬；距高考约 450 天
- 地点：高二（6）班教室 → 走廊 → 车棚
- 出场人物：李洋、周予晚、陈涛（被点名）、前排男生（无名）、英语老师（一句）、孟凡（仅在回忆里）
- 关系位移：李洋与周予晚「同班陌生人」→「互相确认了对方在看自己」；李洋与孟凡「交易双方」→「执行任务的乙方」（他把「你只要看着就行」变成了本子上的五行字）
- 钱：兜里那叠钱（二十四张，对折两次，硌胯）——本章唯一一次钱的出现，与第 1 章的 2400 呼应；末尾草稿纸压在钱上面
- 分数：墙上贴的是**上学期期末班级成绩表**，表头「高二（6）班」，共 47 行——第一行周予晚 1；第四十五行陈涛 26；**第四十六行是他，46**。他仰头才看得到第一行。名次由前排男生当众说出（"他后面第五排那位，四十六吧，你说是吧。"）
- 物件：他的记录本（新一页，角上翘着）；本子上五行字——前四行是无害的（第三排进门数第七个位子／三本笔记物理蓝皮在最上／白水／划掉的「接卷子用右手」），**第五行是越界的「她今天回头看了我。两秒。」，不划掉，只在“回头”两字上描了一遍，笔尖透到纸背**；她递来的草稿纸（折了一次，上面写着「你是谁」，压在钱上面）；她的铅笔（桌沿右边，横放，笔尖朝里）；她的杯子（杯底无水印）；她的橡皮（杯子右边）
- 动作标记：三次「搓裤缝」递进——第一次搓了收住 → 第二次不收 → 结尾骑出去时右手没去搓；口头习惯「重复对方末词」首次亮出（男生问"你说是吧"，他答"是吧？"，全班笑，他立刻低头）
- 遗留：
  1. **「你是谁」的含义未落地**——她不是不认得他，她问的是他要干什么（口径见 `04-知识边界.md` 第 2 章待澄清条）
  2. 那张纸他带回了家，压在钱上面
  3. 本子上那行越界记录没有交出去，但也没划掉（第 3 章交报告时的第一处失守）
  4. 他主动问了「这纸是你的？」，她答「你觉得呢」——两人第一次直接对话

  - 练习本最后撕下的一张纸：抄报告前擦掉两处——「医务室」那一行（擦到第三下「务」字破洞）与「捡笔」两个字

  1. 便利贴是谁放的、为什么写「你今天会发现」——他今天并没有去过医务室
  2. 他向她隐瞒了「她哥」那场对话（答孟凡「嗯。没有。」）
  3. 那行越界记录还在本子上，没划掉也没交
  4. 「你是谁」的含义仍未落地

### ch023 · 母亲不肯说的那三年

- 时间：暑假 七月（距高考约 335 天）；周六透析日淋了雨
- 地点：家里（母亲床边、抽屉、床底）
- 出场人物：李洋、陈桂芝（母亲）
- 关系位移：**母子第一次正面冲突**；她第一次动怒、第一次叫他大名
- 钱（本章的秤）：他报数「一个月一千六，一年一万九千二，五年九万六」；母亲半承认——「这个月的一千六，前天交的，交完抽屉里剩**三百二十七**」「剩下的那些，早花完了」「你没算过你自己的学费」；她把那张盖蓝章的**一千六费用单**推到桌上：「这是我这个月的」「下个月还有」
- 分数：无
- 物件与事实：
  - **发烧说梦话**：体温表 38.9℃；十二点出头说胡话，先是听不清（像在点谁的名字）→「……那个钱……」→停一次呼吸→「**不能要。**」他听清了四个字，**没接话**
  - **锁的是他自己那只马口铁盒**（装真报告、协议那半张、复印件与缴费单）；挂锁是母亲买的（一块五，钥匙串在抽屉小铁锁上，**钥匙用手帕包好塞进抽屉最底下压在病历本下**）；他拽锁鼻三下、铁挂耳弯了一丝——**再拽两次就能开，他停手了**
  - **旧工牌不在盒里**（他前晚拿出来放在桌上，后来收进书包夹层）——这条线没被锁死
  - 母亲的威胁：停他的书、去跟舅学修车、「说到做到」；她烧过一场站不直，用手撑着柜子边
- 章末钩子：他捏着那把挂锁原配的小铝环（弯的地方一道白亮的口子），捏了很久
- 字数：3072

### ch024 · 木匠铺的夜

## 时间线总闸（唯一事实来源）
