- 分数：周予晚年级第一（上学期期末也是第一）；李洋 46/47（人物卡背景，正文未报）
- 物件：牛皮纸信封（未封口、边角起毛）；收据（南洲一中 / 贫困生补助 / 日期填上学期末最后一天 / 签名栏上一行已有笔迹，正文未写名字）；李洋的旧自行车（车座用电工胶布缠两圈）；市二院门诊条子（上礼拜六的，被汗浸黄）；排课表（四月那几格用铅笔画了圈）；校门口银杏标牌「1897—」

### ch002 · 第一名坐在我前面两排

- 时间：与第 1 章同日晚自习，18:25—22:00；晴转夜，三月中旬；距高考约 450 天
- 地点：高二（6）班教室 → 走廊 → 车棚
- 出场人物：李洋、周予晚、陈涛（被点名）、前排男生（无名）、英语老师（一句）、孟凡（仅在回忆里）

- 钱：兜里那叠钱（二十四张，对折两次，硌胯）——本章唯一一次钱的出现，与第 1 章的 2400 呼应；末尾草稿纸压在钱上面
- 分数：墙上贴的是**上学期期末班级成绩表**，表头「高二（6）班」，共 47 行——第一行周予晚 1；第四十五行陈涛 26；**第四十六行是他，46**。他仰头才看得到第一行。名次由前排男生当众说出（"他后面第五排那位，四十六吧，你说是吧。"）

- 动作标记：三次「搓裤缝」递进——第一次搓了收住 → 第二次不收 → 结尾骑出去时右手没去搓；口头习惯「重复对方末词」首次亮出（男生问"你说是吧"，他答"是吧？"，全班笑，他立刻低头）
- 遗留：
  1. **「你是谁」的含义未落地**——她不是不认得他，她问的是他要干什么（口径见 `04-知识边界.md` 第 2 章待澄清条）
  2. 那张纸他带回了家，压在钱上面
  3. 本子上那行越界记录没有交出去，但也没划掉（第 3 章交报告时的第一处失守）
  4. 他主动问了「这纸是你的？」，她答「你觉得呢」——两人第一次直接对话

  1. 便利贴是谁放的、为什么写「你今天会发现」——他今天并没有去过医务室
  2. 他向她隐瞒了「她哥」那场对话（答孟凡「嗯。没有。」）
  3. 那行越界记录还在本子上，没划掉也没交
  4. 「你是谁」的含义仍未落地
