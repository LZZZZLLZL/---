### ch001 · 办公室里的八百块

- 时间：高二下学期，三月中旬，周三放学后；晴，银杏刚冒芽；距高考约 450 天
- 地点：南洲一中教师办公楼三层 · 孟凡办公室 → 走廊 → 校门口 → 城南路口
- 出场人物：李洋、孟凡、一个高一女生（无名，抱卷子，不推动情节）
- 关系位移：李洋与孟凡「师生」→「交易双方」；李洋与周予晚「同班陌生人」→「被指派的目标」（李洋单方面）
- 钱：每月 800；一学期四个月共 4800；先付 2400（二十四张），余额 2400 期末结；参照项——透析单次 400、一周两次、月 8 次 3200、报一半自付 1600；收据原本印"四百元"，被蓝笔改成"八百"
- 分数：周予晚年级第一（上学期期末也是第一）；李洋 46/47（人物卡背景，正文未报）
- 物件：牛皮纸信封（未封口、边角起毛）；收据（南洲一中 / 贫困生补助 / 日期填上学期末最后一天 / 签名栏上一行已有笔迹，正文未写名字）；李洋的旧自行车（车座用电工胶布缠两圈）；市二院门诊条子（上礼拜六的，被汗浸黄）；排课表（四月那几格用铅笔画了圈）；校门口银杏标牌「1897—」
- 动作标记：签收据时右手食指中指在裤缝上搓了四下；紧张时脚尖抵地砖缝；口头习惯「重复对方最后一个词」已用一次（重复"期末"）
- 遗留：
  1. 孟凡漏的那句"你父亲当年也在这条线上跑过车"，随即改口——李洋没有追问
  2. 孟凡隔门缝补的那句"周予晚她哥的事，你知道吗"——李洋答"不知道"，门就合上了
  3. 收据签名栏上一行是谁的字（他认得，没说）
  4. 排课表上四月那几格为什么被圈
- 字数：3088

### ch002 · 第一名坐在我前面两排

- 时间：与第 1 章同日晚自习，18:25—22:00；晴转夜，三月中旬；距高考约 450 天
- 地点：高二（6）班教室 → 走廊 → 车棚
- 出场人物：李洋、周予晚、陈涛（被点名）、前排男生（无名）、英语老师（一句）、孟凡（仅在回忆里）
- 关系位移：李洋与周予晚「同班陌生人」→「互相确认了对方在看自己」；李洋与孟凡「交易双方」→「执行任务的乙方」（他把「你只要看着就行」变成了本子上的五行字）
- 钱：兜里那叠钱（二十四张，对折两次，硌胯）——本章唯一一次钱的出现，与第 1 章的 2400 呼应；末尾草稿纸压在钱上面
- 分数：墙上贴的是**上学期期末班级成绩表**，表头「高二（6）班」，共 47 行——第一行周予晚 1；第四十五行陈涛 26；**第四十六行是他，46**。他仰头才看得到第一行。名次由前排男生当众说出（"他后面第五排那位，四十六吧，你说是吧。"）
- 物件：他的记录本（新一页，角上翘着）；本子上五行字——前四行是无害的（第三排进门数第七个位子／三本笔记物理蓝皮在最上／白水／划掉的「接卷子用右手」），**第五行是越界的「她今天回头看了我。两秒。」，不划掉，只在“回头”两字上描了一遍，笔尖透到纸背**；她递来的草稿纸（折了一次，上面写着「你是谁」，压在钱上面）；她的铅笔（桌沿右边，横放，笔尖朝里）；她的杯子（杯底无水印）；她的橡皮（杯子右边）
- 动作标记：三次「搓裤缝」递进——第一次搓了收住 → 第二次不收 → 结尾骑出去时右手没去搓；口头习惯「重复对方末词」首次亮出（男生问"你说是吧"，他答"是吧？"，全班笑，他立刻低头）
- 遗留：
  1. **「你是谁」的含义未落地**——她不是不认得他，她问的是他要干什么（口径见 `04-知识边界.md` 第 2 章待澄清条）
  2. 那张纸他带回了家，压在钱上面
  3. 本子上那行越界记录没有交出去，但也没划掉（第 3 章交报告时的第一处失守）
  4. 他主动问了「这纸是你的？」，她答「你觉得呢」——两人第一次直接对话
- 字数：3102

### ch003 · 第一张便利贴

- 时间：第 2 章的**次周**（周一—周四），三月下旬；周三早上天阴；距高考约 442 天
- 地点：高二（6）班教室 → 走廊/水房/医务室门口 → 教师办公楼（孟凡办公室）→ 教室
- 出场人物：李洋、孟凡、周予晚（全程无台词，只远处出现）、无名同学
- 关系位移：李洋与孟凡「执行任务的乙方」→「**第一次隐瞒的乙方**」（他藏了两件事：她的三次医务室、他她之间那场对话）；李洋与周予晚「互相确认在看」→「她开始反过来确认他」
- 钱：（严格照「钱的全流程」表）**−1600 交医院（一个月），余额 800**；口述「一次四百，八次三千二，报一半」；孟凡问「你妈这周的透析」，他答「周二做了一次，周六再去」
- 分数：报告正文不涉分数；墙上/宣传栏另有上学期期末排名作背景（第一格最上行被晒白）
- 物件：
  - 他的记录本（新一页写日期）：记「周三，医务室，三次」，括号里三个时间 7:45 / 12:40 / 18:10
  - 练习本最后撕下的一张纸：抄报告前擦掉两处——「医务室」那一行（擦到第三下「务」字破洞）与「捡笔」两个字
  - **本子上那行越界记录「她今天回头看了我。两秒。」：他没抄，笔尖在那行上停了，留下一个小蓝点，翻页过去**（第 2 章遗留第 3 条的兑现）
  - 交上去的报告：两行——「周一至周三：教室、食堂、教室。/ 无异常。」
  - **便利贴**（全书首现）：淡黄、巴掌小一圈、边上浅锯齿、校门口小卖部三块钱一本；粘在他桌洞内壁左侧，有字一面朝外，他用指甲从右下角撬起、粘性粘住食指；正面铅笔字**「你今天去了医务室三次。」**；背面右上角更小一半的字**「你今天为什么会去？」**，最后一笔收得短、收在纸边上（与第 2 章草稿纸同手）
  - 医务室：绿门，漆掉一块，门牌「室」字右下角被撕过一回
- 动作标记：口癖「嗯」用两次（答孟凡）；重复末词「近？」（孟凡问「她在班里跟谁近」）；搓裤缝落在孟凡办公室（与第 1 章同房间，第三次递进的变体）
- 三次医务室的观察距离递进：第一次站在走廊口没往里走 → 第二次没跟（只数到六分钟、看见她手背贴白胶布）→ 第三次站到了门口
- 遗留：
  1. 便利贴是谁放的、为什么写「你今天会发现」——他今天并没有去过医务室
  2. 他向她隐瞒了「她哥」那场对话（答孟凡「嗯。没有。」）
  3. 那行越界记录还在本子上，没划掉也没交
  4. 「你是谁」的含义仍未落地
- 字数：2983
