## 为什么用 bundle 而不是 push

`git push origin main` 返回 **403**：当前 git 凭据（`pppp-hhhh`）对
`LZZZZLLZL/You-Who-Sat-Beside-My-Desk` 没有写权限。要推上去需要：
1. 让仓库属主把该账号加为协作者；或
2. 换一个有写权限的凭据，或改推到你自己的仓库。
