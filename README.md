## 第一名有罪

见 `第一名有罪/README.md`。要点：

- **怎么读**：双击 `第一名有罪/启动阅读器.command`（专用阅读器，带目录、进度、书签、全文搜索、排版设置）
- 写作工程共 12 份编号文档 + 三个正文目录（`chapters/` 定稿、`drafts/` 草稿、`reports/` 审核报告）
- 工作流：写手 → 评审 → 主编定稿 → 档案员归档，一章一循环
- 三条铁律：绝不既写又审 / 知识边界是闸门 / 一章一循环

- `.gitignore` 排除工具产物、Python 缓存、`.env`、`.DS_Store`
- 两个项目各自独立，**不要在项目之间互相引用文件路径**
- 每次推进一个批次后提交一次，提交信息写清「哪个项目 + 干了什么」
